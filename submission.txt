Known Issues / Future Work

Known issues
- A missing id (e.g. /ratings/999) shows Spring's default error page rather than a custom 404 page.
- The unique email check is case-insensitive in the controller, but the database constraint is case-sensitive, so two requests at the same moment with emails that differ only by case could both get through.
- The Render free plan sleeps after inactivity, so the first page load can be slow.
- I could not run the test suite in the environment where the code was drafted, so run `mvn test` before submitting and fix anything that fails. <DELETE THIS LINE ONCE YOU HAVE RUN THEM>
